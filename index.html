ABOUT THIS WORKSPACE

Made for thoughtful lesson design.

The app runs on your computer. Topic searches use public research catalogs; with AI configured, the server can search the wider web and draft from cited results. Your saved lessons stay local.

Optional AI uses a key stored on your own local server in a .env file. It is never sent to the browser. See the README for setup. AI output still needs source and instructor review.
THE LESSON STUDIO METHOD

A lesson grows in four passes.

  1. BriefName the skill learners should demonstrate.
  2. ResearchCollect website, book, and video sources. Check them yourself.
  3. BuildShape the evidence into a paced sequence with examples and practice.
  4. ReviewCheck claims and learner fit separately; apply fixes, then review again.

Without an AI key, Lesson Studio still researches websites and books, then creates an evidence-first draft. AI generation is optional. When enabled, AI can perform a wider web search and write the lesson flow from the sources it finds.
